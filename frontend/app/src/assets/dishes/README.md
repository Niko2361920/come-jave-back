# Fotos de los platos

Pon aquí las fotos reales de cada plato. El nombre del archivo es el **id del plato**:

| Ventolini | id   | La Frute      | id   |
| --------- | ---- | ------------- | ---- |
| Bolognesa | `p1` | Bowl Açaí     | `b1` |
| Alfredo   | `p2` | Bowl Proteico | `b2` |
| Pesto     | `p3` | Bowl Tropical | `b3` |
| Margarita | `z1` | César         | `e1` |
| Pepperoni | `z2` | Mediterránea  | `e2` |
| Hawaiana  | `z3` | Verde         | `e3` |

Ejemplo: `p1.webp`, `z2.jpg`, `b3.png` (también `.jpeg` y `.avif`).

- Se detectan al compilar: no hay que tocar código. Si falta una foto, la app muestra la ilustración de ese plato.
- Se recortan en círculo, así que sirven fotos **cuadradas** con el plato centrado (recomendado 600 × 600 px, formato WebP, menos de 80 KB).
- Usa fotos propias o con licencia que permita su uso (por ejemplo, las que tomen los restaurantes).
